# Kernel extraction

Coq → OCaml extraction of the six boolean kernel validators.

This produces a **generated executable artifact for testing**.
OCaml extraction is mechanically generated by Coq extraction,
useful for testing, and **NOT** formally proven semantics
preserving. It is not a C++ node, not a CompCert refinement,
and not a cryptographic library.

`EXTRACTION_FORMAL_PROOF=source_identity_only`
`EXTRACTION_EQUIVALENCE_NOT_CLAIMED=TRUE`
`PRODUCTION_REFINEMENT_NOT_CLAIMED=TRUE`

```
cd formal_verification/rigor_kernel
make
./extraction/build.sh
```

Output: `ExtractedKernel.ml` (and `.mli`).

`KERNEL_EXTRACTION=PASS` means the extraction vernacular succeeded.

Not claimed: C++ equivalence, full-node correctness, SHA3/Ed25519
security, CompCert refinement.
