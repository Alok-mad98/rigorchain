# Security documentation

This directory contains the public security principles and the security boundary.

It states how RIGOR may study external security research without changing the frozen protocol.

Engineering audit records, vulnerability analysis, and internal security checks are kept in the private maintenance repository. They are not part of this directory.

Public document:

- [RIGOR Security Patch Boundary](./RIGOR_SECURITY_PATCH_BOUNDARY.md)

That document does not define consensus rules, and it does not authorize protocol changes.
