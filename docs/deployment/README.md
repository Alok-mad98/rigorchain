# Deployment documentation (public)

This directory is for **protocol-facing** deployment notes only: how a
developer runs a node from published artifacts, which ports the protocol
uses, and which secrets must never be shipped.

Operator runbooks, host inventories, SSH access, and production firewall
state are **internal**. They live outside this repository (`ops-internal/`
on an operator machine) and are not committed.

See [DOCUMENTATION_CLASSIFICATION.md](../DOCUMENTATION_CLASSIFICATION.md).
