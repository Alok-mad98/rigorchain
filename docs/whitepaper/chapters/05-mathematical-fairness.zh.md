# 第五章 — 可核对的数学：谓词、缩放因子与导出上界

第四章固定了验证动作。本章把那条谓词展开，使任何人都能用纸笔或一段整数程序核对：展示式与共识式是同一关系；上限是导出的，不是宣告的；公平是同一公开输入得到同一判定。

此处的主张仍是架构主张。数学固定的是 **变换的形状**。它不固定有人会走这座桥，也不固定外部价格。

数字的唯一事实源是 RFC-020 的脚本。本章的式子与那份脚本一致。没有一处是手算出来的。

---

## 5.1 公平是什么

本章的公平是一条公开判定函数：

```
同一 (R, B, h)  →  同一承认或拒绝
```

`R` 是本笔铸造的 RES 原子，`B` 是可见销毁的 ORU 原子，`h` 是确认高度。三者都在区块字节里。没有第四个隐藏参数。没有未公开的费率。没有矿工可以改写的随机项。

因此公平可以当场核对。给定一笔已确认交易，任何人重算不等式，必须得到与全网相同的对错。本章的公平指确定性、可公开重放的承认或拒绝。它不意味着铸造数量相等、时点相等或经济结果相等。在共识规则内，该判定是 `(R, B, h)` 的公开精确函数。

---

## 5.2 展示式与共识式是同一条恒等式

阅读用的销毁成本是

```
destroy_cost(h) = 1024 · (2²⁵ + h)² / 2⁵⁰
```

`2⁵⁰` 是 `destroy_cost(h)` 的 **曲线归一化分母**：`(2²⁵)² = 2⁵⁰`。它不是共识移位。

展示辅助函数可以用整数除以 `2⁵⁰`（右移 50 位）求该商。该向下取整只供阅读。展示用的 rounding 与 floor **不进入共识**。共识从不除以 `2⁵⁰`。它计算 `B << 40`。

创世处恰好是 1024 ORU / 整枚 RES。共识从不做这次除法。整数谓词是铸造条件的精确整数形式，不是近似、简化估计或优化公式。它与展示成本条件代数等价。不发生舍入或截断。共识计算消去除法之后的那一关系：

```
R > 0  →  R · (2²⁵ + h)² ≤ B << 40
R = 0  →  B 不受此谓词约束
```

`2⁴⁰` 是消去 `1024 = 2¹⁰` 之后的 **整数共识缩放因子**（`50 − 10 = 40`）。它不是 `destroy_cost` 的分母。展示分母仍是 `2⁵⁰`。

从展示式到共识式是精确的、保持整数的等价，不是近似：

```
R · destroy_cost(h)                 ≤  B · RES_COIN
R · 1024·10⁸ · (2²⁵+h)² / 2⁵⁰      ≤  B · 10⁸
R · 1024   · (2²⁵+h)²              ≤  B · 2⁵⁰
R · 2¹⁰    · (2²⁵+h)²              ≤  B · 2⁴⁰ · 2¹⁰
R          · (2²⁵+h)²              ≤  B · 2⁴⁰
```

`RES_COIN = 10⁸` 在两侧约去。`1024 = 2¹⁰`。共识缩放因子因此被创世成本强制推出：

```
RES_DESTROY_SHIFT = 50 − log₂(1024) = 40
```

换一个创世成本，缩放因子跟着动，其余不变。`40` 不是单独挑选的「好看的数」。改创世成本却不改缩放因子，恒等式会破，谓词就不再表示那条展示曲线。

共识执行一次乘法、一次平方、一次移位。没有除法，没有向下取整，没有开方，没有 epoch 指数，没有价格表。`check_mint` 是精确的，所以没有舍入方向需要规定。`destroy_cost(0)` 恰好是 1024。

免费铸造不可表示：每一个 `h ≥ 0`，`destroy_cost(h) > 0`，且铸造 1 枚原子的最小销毁至少为 1。

## 5.3 为何指数是 2

记 `S = 128 = 2⁷`（每块 ORU 补贴），`P0 = 1024 = 2¹⁰`（创世整枚成本），`H = 2²⁵`（极点）。展示式是

```
destroy_cost(h) = P0 · (H + h)² / H²
```

一块补贴在该高度最多能换到的 RES 是 `S / destroy_cost(h)`。沿高度把每块上限收成一式：

```
∫_0^∞ S / destroy_cost(h) dh
  = (S / P0) · H² · ∫_0^∞ (H + h)⁻² dh
  = (S / P0) · H
```

指数恰好为 2，封闭式才恰好是 `(S / P0) · H`，没有余项。因此上限落在 2 的幂上，而不是落在附近：

```
RES_MAX_SUPPLY = 2⁷ / 2¹⁰ · 2²⁵
               = 2²²
               = 4 194 304 RES
               = 419 430 400 000 000 原子
```

主要发行常数选取为 2 的幂，以便简化算术核验。上限的推导直接来自指数关系。改动其中任一常数，可见的恒等式就会破，而不是悄悄平移一条曲线。

到任意高度的累计上限也有封闭形式：

```
cumulative(h) = RES_MAX_SUPPLY · h / (h + 2²⁵)
```

这是同一封闭式在有限高度上的形式。极点 `h = 2²⁵` 的操作含义是：在全额参与时，发行分布的中位数恰好落在那里。那一年累计为上限的一半，销毁成本约为 4 096 ORU / RES。

工具不必维护一个运行中的累计计数器。任一高度的上界都可以当场算出来。

## 5.4 为何上限不需要共识计数器

导出上界是 **上界**，不是日历承诺。论证是交换论证，前提是 `destroy_cost` 严格递增——这一点本身可核对。

任意高度前被销毁的 ORU，不能超过当时已经发行的 ORU：ORU 不能在存在之前被销毁。成本严格递增，故 `1 / destroy_cost` 严格递减。使 RES 总量最大的策略，是每一枚新发行的 ORU 在它出现的那个高度立即销毁。该策略的总和就是上一节的封闭式。任何延迟都只会得到更少 RES。

因此：

- 没有任何囤积策略能从上方触及该界；
- 验证区块时不必查询「至今已铸多少」；
- 实现存量恰好是 `ρ · 2²²`，其中 `ρ` 是终将被销毁以铸造 RES 的发行份额。

运行时仍可保留一条「不得超过上限」的防御检查。一条永不会触发的检查很便宜；推导若有洞、现场却没有检查，代价不是。

铸造在整块补贴买不起 1 枚 RES 原子时结束。结束高度由同一套整数算术给出，不是另设的参数。

## 5.5 128 出现在恒等式的分子上

ORU 补贴是平坦的：

```
subsidy(0) = 0
subsidy(h) = 128 ORU          对每一个 h ≥ 1
```

`128 = 2⁷` 不是装饰。它是上限恒等式的分子。把它改成别的数，`2²²` 不再成立，除非同时改 `P0` 或 `H`。矿工预算的协议地板，与稀缺存量的封闭上界，是同一组 2 的幂里的两个位置。

通胀速率按 `1/t` 衰减，趋向零而不达到零。剩余通胀水平仍是 `1 − ρ`。数学不创造 `ρ`。它只蕴含：若 `ρ` 被观察到，实现的 RES 与剩余的 ORU 通胀可以当场从定义读出。

## 5.6 可当场核对的探针

下列探针由数值唯一事实源打印。任一实现若在这些高度上偏离，就不是这一条曲线。

| 高度 | 原子 | ORU / 1 RES |
|-----:|-----:|------------:|
| 0 | 102 400 000 000 | 1 024 |
| 210 000 | 103 685 749 152 | 1 036.857 491 52 |
| 420 000 | 104 979 520 049 | 1 049.795 200 49 |
| 630 000 | 106 281 312 688 | 1 062.813 126 88 |

单块成本变化约为 0.000 089%。钱包按确认高度加一段平坦裕度构造即可。过大的裕度是舍入误差，不是策略。展示式不得倒填为 `B`：构造必须满足不等式本身。

最坏情况下谓词左端约 `2¹¹⁰`、右端约 `2⁹⁹`，对着 `unsigned __int128` 的 `2¹²⁸`。乘法、平方、移位在该宽度内不溢出。这是算术事实，不是供给政策。

## 5.7 「同一输入同一判定」如何成为公平

把 5.1 与前面各节合在一起，公平有四层，每一层都可以核对：

| 层 | 公开对象 | 核对什么 |
|----|----------|----------|
| 谓词 | `(R, B, h)` | 承认或拒绝不含随机项、不含隐藏费率 |
| 恒等 | 展示式 ↔ `<< 40` | 移位被创世成本强制；两侧是同一关系 |
| 上界 | `(S / P0) · H = 2²²` | 上限由恒等式读出，不是治理写入 |
| 交换 | 成本严格递增 | 延迟只能更少；验证不必查累计器 |

没有人需要相信操作者「会按表执行」。表就是不等式。没有人需要相信矿工「不会多铸」。多铸的字节使不等式失败，整笔无效。没有人需要相信「上限稍后会有人守」。守上限的是交换论证，不是一条必须被更新的全局计数。

这不是结果均等。先到的铸造者按更低单位成本进入，这是第一章按时长付费的数学形式，不是漏洞。这形成一套对持有时长敏感的成本日程：更早参与者获得更低的协议定义销毁成本，因为它在高度时间线上更早锁定资本。共识规则内的公平，仍是对该曲线的确定性公开求值，而不是一条被改过的私表。

高度 `h` 本身来自工作量证明给出的顺序。数学假定确认高度是全网同一的那一个。如何发现并排列那个高度，是第六章的主题。

## 5.8 本章不主张什么

- 不把探针写成市场价格，也不把导出上界写成「一定会被走满」。
- 不断言 C++ 与内核模型形式等价。脚本中的断言与 Coq 陈述同名；模型证明选定不变量，不证明 `ConnectBlock`。
- 不把「公平」写成经济收益承诺。
- 不把 `128`、`1024`、`2²⁵` 写成独立的吉祥数字。它们是一条恒等式里的三个指数。
